# Chameleon - IFR Builder Registry Status

## Current Status

Builder-registry governance is an external IFR ecosystem matter and is not part of the
Chameleon Android trust or entitlement model. Chameleon does not query a builder registry,
an IFR lock contract or any wallet from the app.

Any future registry listing may identify the project publicly, but it cannot grant Android
features. Paid access is granted only by a server-signed, device-bound activation credential
issued after the seller's approved checkout and fiscal flow.

Earlier drafts that referenced `IFRLockVerifier`, `IFRTierActivator` or a wallet-derived
`TierGatedContent` flow are historical and no longer describe the repository.
